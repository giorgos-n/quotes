# quotes

Αυτό το αποθετήριο περιέχει ένα μικρό Random Quote Generator (HTML/CSS/JS).
Ο φάκελος quote.project περιλαμβάνει τα αρχεία:
- index.html
- styles.css
- script.js

Οδηγίες
1. Άνοιξε το `index.html` σε browser.
2. Κάνε κλικ στο "New Quote" για να εμφανιστεί μία τυχαία φράση.
3. Χρησιμοποιεί localStorage για να θυμάται το θέμα (dark/light).
